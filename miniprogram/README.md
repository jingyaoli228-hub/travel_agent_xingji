# 行迹微信小程序

这是云端 FastAPI 的原生微信小程序客户端，不依赖 React/Vite，也不要求电脑保持开机。

## 本地预览

1. 打开微信开发者工具，导入本目录。
2. `project.config.json` 已配置当前项目的正式 AppID；如需更换主体，请同步替换为新主体的 AppID。
3. `config.js` 默认连接本机 `http://127.0.0.1:8000`；连接云端时改成正式 HTTPS API 域名。
4. 本地联调 HTTP/自签名地址时，仅在开发者工具中临时关闭“校验合法域名”；发布版本必须使用微信后台登记过的 HTTPS 域名。

## 发布前必须完成

- 为后端配置域名、HTTPS 和微信公众平台的 request 合法域名。
- 后端增加微信登录、用户身份与资源所有权校验；当前云端版本不可直接公网开放。
- `apiBaseUrl` 不要带末尾 `/`。

## 已支持

- 会话 ID / 用户 ID 本地持久化。
- 多轮需求确认和会话恢复。
- 后台研究任务状态轮询。
- 候选体验分组展示。
- 最终逐日行程与警告展示。
- 新建规划（不会删除云端历史）。
