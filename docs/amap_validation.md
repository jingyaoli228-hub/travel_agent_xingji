# 高德替换与真实验证结论

验证日期：2026-10-17。测试使用 Web 服务类型 Key，密钥未写入本文档或源码。

## 实测结果

| 能力 | 中国大陆样例 | 东京样例 | 结论 |
|---|---:|---:|---|
| 地点搜索 2.0 | 北京故宫返回真实 POI | 表面成功但命中苏州同名餐厅 | 必须校验返回行政区；普通 Key 不能作为可靠海外 POI 源 |
| 地点详情 2.0 | 评分、营业时间、电话、图片可用 | 依赖海外地点搜索，无法由普通高德 Key 保证 | 高德不提供 Google 风格评论正文与评论数 |
| 步行路线 2.0 | 成功，返回距离、时长、步骤与坐标串 | `20800 OUT_OF_SERVICE` | 普通 Key 的路径规划不能完整覆盖海外 |
| 天气 | 北京短期预报成功 | 高德不可靠 | 高德约 4 天，且没有降雨概率字段 |

高德官方错误码说明中，`20011` 表示没有海外地图权限，`20800` 表示规划点不在中国大陆服务范围。

## 当前实现

- 中国大陆：高德地点搜索/详情、路线规划、天气。
- 海外地点：高德结果未通过行政区校验时，降级到 OpenStreetMap Nominatim，并遵守每秒最多一次请求。
- 海外天气及第 5-16 天预报：Open-Meteo。
- 海外精确路线：不伪造为高德结果；当前返回不可用，由 Planner 显示明确标注的预估时长。
- 高德 Web 服务 Key、浏览器 JS Key、安全密钥分离，HTTP 调试日志禁用，防止查询串泄漏密钥。

因此，高德可以完整替代本项目在中国大陆的核心地图能力，但不能用普通 Key 完整替代 Google 的全球
地点、路线和天气能力。混合降级方案让小程序仍可规划海外地点与天气，同时如实标注海外路线限制。
