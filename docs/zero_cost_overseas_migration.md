# 零新增费用海外迁移与微信小程序上线清单

## 已确认的产品限制

- 腾讯云轻量应用服务器创建后不能直接更换地域。
- 跨地域只能通过“自定义镜像 → 跨地域复制 → 在目标地域新建实例”迁移。
- 目标实例会计费，跨地域复制后的自定义镜像也可能计费；因此不能在不知道退款和余额的情况下直接创建。
- 上海实例关机不会产生新的按量运行费，但包年包月有效期仍会继续消耗。

## 零新增现金的唯一可行判定

在腾讯云控制台分别记录：

1. 上海实例“退还/销毁”页面显示的**预计退款金额**（只查看，不提交）。
2. 账号当前可用余额。
3. 新加坡、东京、中国香港三地满足 `4 核 / 4 GB / 60 GB` 或更高配置的**实际应付金额**。

仅当 `预计退款 + 可用余额 >= 海外实例实际应付金额 + 必要镜像费用` 时，才满足“无需额外花钱”。活动券通常不会返还，不能按原购买价推算。

## 推荐地域顺序

1. 新加坡：通常能直连 Google、GitHub、Exa，面向中国用户的延迟可接受。
2. 东京：Google 生态可用，延迟通常也可接受。
3. 中国香港：距离近，但套餐库存、价格和跨境线路需要以账号控制台实测为准。

不要再次选择中国内地地域，否则 Google Places/Routes 与 GitHub 仍可能被网络出口阻断。

## 安全迁移顺序

1. 保留上海实例，不提交退还。
2. 使用本地 `scripts/package_for_server.ps1` 生成无密钥部署包。
3. 确认海外套餐可被退款余额完整覆盖。
4. 如需保留服务器运行态，先做自定义镜像并查看跨地域复制费用；若费用不为零，直接用本地部署包重建更省钱。
5. 用户本人确认并提交上海实例退款；这是不可逆财务操作。
6. 退款到账后，用户本人确认购买海外实例；不得勾选自动续费或额外数据盘。
7. 上传部署包，写入密钥，启动 Compose，迁移 PostgreSQL/Redis/Chroma 数据。
8. 验证 DeepSeek、Google Places/Routes、Exa、RAG、完整规划、重启持久化和 Worker 恢复。
9. 配置正式域名、HTTPS、微信 request 合法域名、微信登录和资源所有权校验后，才开放公网。

## 微信小程序

原生客户端位于 `miniprogram/`，默认连接本机 `http://127.0.0.1:8000`。海外 API 上线后只修改 `miniprogram/config.js`：

```js
module.exports = {
  apiBaseUrl: "https://api.your-domain.example"
}
```

正式发布还需要用户提供：

- 微信小程序正式 AppID；
- 可控制 DNS 的域名（或已有合规 API 域名）；
- 微信公众平台管理员扫码/审核操作。

这些账号级操作不能由代码替代，也不能通过裸 IP 发布。
